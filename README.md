# OIOSI review publication

This repository contains the generated public website bundle for specialist review. Private application source is maintained separately. The included de-identified reference images are public ISIC data. No reviewer-uploaded photographs, private patient data, credentials or patient database are included.

The site offers guided capture, local browser image-quality guidance and MobileNetV3/ONNX Runtime Web similarity retrieval against 240 permissively licensed, histopathology-confirmed public reference lesions. Similarities and category composition are not diagnostic probabilities. This is an engineering evaluation MVP, not a clinically validated medical device.

Image and dataset attribution is in review/ATTRIBUTION.md and review/index.json, and visible in the application's reference details. Dutch source labels and their originals are preserved in the interface. The future case/pathology database is not implemented. Photographs selected by a reviewer are processed in browser memory and not uploaded to a server.
